About Me

Hello! My name is Abdi Setiawan, a 5th-semester Information Systems student with a strong passion for backend development. I specialize in JavaScript, TypeScript, PHP, and Go, alongside database management with MySQL, MongoDB, SQLite, and Firestore.

I have experience deploying cloud-based applications using Google Cloud Platform services like Cloud Run and Firestore. My technical skills also include Docker for containerization and a basic understanding of frontend development with Vue.js, enabling smooth collaboration across teams.

One of my key projects involved designing a mental health analysis application, where I developed a robust REST API backend integrated with machine learning models and cloud infrastructure. This taught me the importance of teamwork and technical precision.

I am committed to continuous learning and aim to contribute to impactful projects that solve real-world challenges while growing as a backend developer.
